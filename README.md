# ZapretLauncher

Лаунчер для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — включает обход
блокировок Discord и YouTube одной кнопкой и сам следит, чтобы он работал.

Неофициальный: zapret и его стратегии делает [Flowseal](https://github.com/Flowseal), лаунчер только
скачивает их из официального репозитория и запускает.

## Что умеет

- **Включить и выключить** zapret — процессом или службой Windows, вместе с системой.
- **Подобрать стратегию**: по очереди включает все и проверяет, открываются ли Discord, YouTube и другие сайты.
  Видит и блокировку, и «заморозку» соединения после 16–20 КБ.
- **Проверка сети и диагностика**: что открывается сейчас, что мешает zapret (другие обходы, VPN, прокси,
  AdGuard, DNS, hosts) — с исправлениями в один клик.
- **Свои списки**: сайты для обхода, исключения, IP-адреса; импорт и экспорт, русские домены.
- **Трей и сторож**: работает в фоне, перезапускает winws.exe, если тот закрылся.
- **Сеть и страна**: при смене сети проверяет, нужен ли обход, — выключает zapret, если сайты открываются
  и так (например, включили VPN), и включает снова, когда блокировки вернулись.
- **Профили сетей**: помнит стратегию для каждого провайдера и переключает её сам.
- **Обновления**: лаунчер и zapret обновляются сами; если новая версия zapret сломала обход — возвращает прежнюю.

## Установка

Скачайте `ZapretLauncher-Setup-*.exe` со страницы [релизов](https://github.com/notcodeone/zapret-launcher/releases)
и запустите. Нужна Windows 10 1809 или новее (x64) и права администратора — без них WinDivert не работает.

При первом запуске лаунчер предложит скачать zapret или указать папку, где он уже лежит.

Антивирус может ругаться на WinDivert (`RiskTool.Multi.WinDivert`) — это драйвер, через который работает
zapret. Добавьте папку zapret в исключения.

## Сборка

Нужны Flutter 3.47, Visual Studio с компонентом «Разработка классических приложений на C++»
и [Inno Setup 6](https://jrsoftware.org/isinfo.php) для установщика.

```powershell
flutter test
powershell -ExecutionPolicy Bypass -File tool\build_installer.ps1
```

Установщик появится в `dist\`. Релиз — тегом `vX.Y.Z`: GitHub Actions соберёт установщик и опубликует его.

Дизайн — по дизайн-системе NotCode.
