# История версий

Номер версии — в `pubspec.yaml`, как выпускать новую — в README («Версии»).
Раздел версии отсюда становится текстом её выпуска на GitHub.

## 0.2.0 — 2026-10-03

Zapret теперь внутри лаунчера.

### Новое

- Zapret встроен в лаунчер: после установки ничего скачивать не нужно — при первом запуске
  лаунчер сам распаковывает zapret-discord-youtube 1.10.3, даже без интернета.
- «Откуда zapret» в настройках: встроенный или своя папка. Своя папка запускается как есть и
  сама не обновляется. Если zapret работает, он перезапускается уже из выбранной папки.
- Новая версия лаунчера приносит и новый zapret. Он ставится сам, как обновление с GitHub:
  если с ним Discord или YouTube перестали открываться, лаунчер возвращает прежний.
- «NotCode» в подвале ведёт на GitHub NotCode.

### Изменения

- Если при первом запуске zapret уже работает из своей папки (например, `C:\zapret`), лаунчер
  берёт её. Zapret, который лаунчер 0.1.0 скачал в `%ProgramData%\ZapretLauncher\zapret`,
  становится встроенным.
- «Диагностика» ставит недостающий zapret заново из встроенного — без загрузки.

## 0.1.0 — 2026-10-02

Первая версия.

### Новое

- Запуск zapret-discord-youtube одной кнопкой — процессом или службой Windows, которая
  включается вместе с системой. Совместим с `service.bat`: та же служба `zapret`, те же
  файлы игрового фильтра и IPSet.
- Скачивание zapret из официального репозитория Flowseal; можно указать папку, где zapret
  уже лежит.
- Подбор стратегии: лаунчер по очереди включает каждую и проверяет Discord, YouTube, Google
  и Cloudflare. Видит и блокировку, и «заморозку» соединения после 16–20 КБ, отличает
  подмену DNS.
- Проверка сети из шапки: что открывается сейчас, в какой стране и у какого провайдера вы.
- Диагностика — проверки из `service.bat` с исправлениями в один клик: служба BFE, файлы
  zapret, другие обходы, драйвер WinDivert, AdGuard, VPN, прокси, защищённый DNS, hosts.
  Очистка кэша Discord и обновление списка IPSet.
- Свои списки: сайты для обхода, исключения, IP-адреса. Ссылки, строки hosts и русские
  домены; импорт и экспорт.
- Трей: значок с состоянием zapret и меню, крестик прячет окно в трей.
- Сторож: перезапускает `winws.exe`, если тот закрылся сам; служба zapret перезапускается
  средствами Windows.
- Слежение за сетью: при смене сети или страны лаунчер проверяет, нужен ли обход, —
  выключает zapret, если сайты открываются и так (например, включили VPN), и включает
  снова, когда блокировки вернулись.
- Профили сетей: стратегия, игровой фильтр и IPSet запоминаются для каждого провайдера и
  переключаются сами.
- Автозапуск при входе в Windows — свёрнутым в трей и без запроса прав.
- Установщик; самообновление лаунчера из выпусков на GitHub с проверкой SHA-256.
- Автообновление zapret: если с новой версией Discord или YouTube перестали открываться,
  лаунчер возвращает прежнюю и эту больше не ставит.
- Светлая и тёмная темы по дизайн-системе NotCode.
